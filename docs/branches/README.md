## 如何理解“最佳”

- 主规则是**同分支、同评估口径下最低挂量RMSE**，并列价格、大单召回/精确率/F1与挂量动态相关；这与当前main为综合F1选型的规则不同。不能把低挂量RMSE理解为整簿已经恢复好。
- 测试时段、窗口长度、窗口数、有效计数和目标RMS不同的实验分组报告，不构造跨容量/跨口径总冠军。
- 每个分支查找所有已保存正步数检查点的最低挂量误差，包含中间点；这是回顾性选型，不代表同预算结构改进或独立确认。最大共同端点另外标记并报告；早期epoch历史按真实测试记录选点并核对权重epoch。
- 若控制组更好，赢家仍明确标成控制，不将其说成新增结构的收益。分支仍在训练时，结果为共同阶段点。
- **未压缩完整256分钟Cross**与**唯一Gaussian8192**是不同容量；历史16分钟又是不同任务。稀疏地址诊断不是原生Gaussian神经模型。
- 没有正式测试结果的分支写明“暂无”，只有结构/预检证据；缺少最佳点对应预测时仅绘制指标，不挪用其他权重的订单簿。

## 当前8192主线共享骨干

这部分适用于Unified/frame1及其后续紧凑模型，不套用到历史Global/Local、V4/V8或稀疏地址诊断：

- 输入特征通常为基础4通道、双侧差分6通道、六尺度负LoG6通道；新增输入适配另列。空间卷积以四次stride2把2048档降到128个粗区域，主通道64/128/192/256；同帧买卖侧Cross-Attention后汇总。
- patch4按4帧打包后在64个时间token上处理；frame1在256帧上做时间注意力，每帧32个Gaussian坐标重排为64×128。两者只有一个Gaussian；β=0/不采样的实验是确定性重建，不等于已验证先验生成质量。
- 两个Decoder读取同一个Z，先还原每分钟256维特征，再产生双侧128区域×16维种子。空间Decoder四级nearest上采样与卷积，主通道192/128/64/32。
- 价格使用mid、正spread和正gap累加；挂量经q0·Softplus保持非负，并可使用预测价格几何条件。首帧mid锚点、mask/tick/相对时间是元数据，不是Encoder特征跳接。
- 细档位残差、形状/总量、直接MLP、全窗注意力及FNO都是这个共同骨干上的独立研究方向；实际启用开关、数值策略和历史配置见各分支权重JSON。
